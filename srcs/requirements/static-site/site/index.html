I'm a student at 42, focused on systems programming, DevOps, and building things that actually work under pressure.

I enjoy understanding how things work at a low level — from how the kernel manages processes to how containers isolate workloads. This project (Inception) is a reflection of that: infrastructure built from scratch, no shortcuts.
